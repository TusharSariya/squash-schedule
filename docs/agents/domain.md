# Domain docs

## Layout

This repository uses one root CONTEXT.md and docs/adr/.

## Before exploring

Read CONTEXT.md and ADRs relevant to the task.
If they are absent, proceed silently. Domain modeling creates
them as terminology and decisions are resolved.

## Vocabulary

Use the domain terms defined in CONTEXT.md.
Identify missing concepts for domain modeling.

## Decisions

Surface conflicts with existing ADRs explicitly, explaining
which decision conflicts and why it may need reconsideration.
